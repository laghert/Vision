Klucz do Twojego dziennika
Oficjalne API Librus vs Strona WWW

Aplikacja Vision wyświetla Twoje oceny, plan lekcji, frekwencję i powiadomienia za pośrednictwem szybkiego REST API. Librus zablokował bezpośrednie logowanie do API samym loginem szkolnym. Aby aplikacja miała dostęp do danych, konto szkolne musi być powiązane z Kontem LIBRUS.

● Login ze szkoły
  • ✕ Postać: 1234567u
  • ✕ Tylko strona WWW
  • ✕ Sesja wygasa po 2h
  • ✕ Brak tokenu do API ocen
● Konto LIBRUS
  • ✓ Twój adres e-mail
  • ✓ Działa z Vision i API
  • ✓ Trwała sesja (tokeny)
  • ✓ Multikonto rodzeństwa
🔒
100% Bezpieczeństwa
Standard branżowy OAuth 2.0

Logując się przez oficjalne okno przeglądarki w Vision, logujesz się bezpośrednio na serwerach Librusa. Twoje hasło nigdy nie trafia do aplikacji. Vision otrzymuje wyłącznie bezpieczny token autoryzacyjny, który samoczynnie odświeża sesję w tle.

Załóż bezpłatne Konto LIBRUS →
1
Załóż bezpłatne Konto LIBRUS
Wejdź na stronę portal.librus.pl i zarejestruj się, podając swój adres e-mail oraz dowolne hasło.
Wystarczy zwykły adres e-mail
2
Powiąż konto ze szkoły (Synergia)
Po zalogowaniu na portalu kliknij „Powiąż konto z systemem Synergia” i wpisz login ze szkoły (np. 1234567u) oraz szkolne hasło z kartki.
Robisz to tylko jeden jedyny raz!
3
Zaloguj się w Vision
Wróć do Vision, wybierz „Zaloguj przez stronę WWW” i zaloguj się swoim mailem. Vision automatycznie pobierze oceny, plan lekcji i zapamięta sesję.

Czy Konto LIBRUS jest płatne?
Nie! Założenie Konta LIBRUS i powiązanie konta ucznia jest w 100% darmowe. Płatne są tylko opcjonalne dodatki komercyjne w oficjalnej aplikacji, których Vision w ogóle nie wymaga.
Co jeśli mam więcej niż jedno dziecko w szkole?
To największa zaleta! Do jednego Konta LIBRUS (e-mail) możesz powiązać dowolną liczbę uczniów. Vision po jednym zalogowaniu wykryje wszystkie profile i pozwoli na wygodne przełączanie się między nimi.
Dlaczego nie muszę ponownie podawać hasła?
Vision wykorzystuje mechanizm refresh_token zgodny ze standardem OAuth 2.0. Aplikacja w tle periodycznie odświeża sesję, więc nie zostaniesz wylogowany po wygaśnięciu ciasteczek.
